# Bitmap fonts

X11 `misc-fixed` BDF fonts (5x7, 6x10, 9x15B, 10x20) from
https://gitlab.freedesktop.org/xorg/font/misc-misc — **public domain**
("Public domain font. Share and enjoy."). Classic 5x7 matrix look, Latin-1 incl. accents.
The mockup tool (`tools/mockup`) renders with the same files, so mockups match the board 1:1.
